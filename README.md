🌍 RoamWise – Travel Planner

Plan your trips, explore destinations, and travel smarter with RoamWise!

RoamWise is a React-based travel planner application that helps users discover destinations, explore nearby attractions, check weather conditions, and plan trips with friends. It also includes a group budget calculator to estimate total expenses and per-person costs.

✨ Features

Destination Discovery: Explore popular destinations and view their details.

Weather Information: Check weather conditions using the Open-Meteo API.

Interactive Maps: Explore destinations and locations using React Leaflet.

Nearby Places & Food: Discover nearby attractions, restaurants, and food places.

Trip Planner: Enter trip details through a planner form to organize your travel plans.

Group Budget Calculator: Calculate estimated trip expenses and cost per person when travelling with friends.

Wishlist: Save your favourite destinations for future trips using localStorage.

User  UI: Sign-up and sign-in forms with input validation.

Festivals & Travel Advice: Explore festivals by month and find useful travel tips.

🛠️ Technologies Used

Frontend: React.js

Build Tool: Vite

Styling: Bootstrap and CSS

Routing: React Router

Maps: React Leaflet

Weather API: Open-Meteo API

Data Storage: JSON files and browser localStorage

🎯 Project Objective

The objective of RoamWise is to simplify travel planning by bringing destination exploration, weather information, nearby places, trip organization, and group expense calculation together in one user-friendly application.
